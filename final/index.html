Üye Yönetimi

Nasıl Yeni Üye Eklenir?

  1. Supabase Dashboard → Authentication → Users → Add user ile e-posta+parola oluştur.
  2. User Metadata (Raw) alanına JSON olarak gir: 
    {
  "full_name": "Ahmet Yılmaz",
  "department": "yazilim",
  "username": "ahmet"
}
  3. Üye giriş yaptığında otomatik olarak aşağıdaki listede görünür. Buradan departman ve rolünü değiştirebilirsin.
  4. Departmanı boş bırakılan üyeler hiçbir korumalı veriye erişemez (kasıtlı: admin onayı bekler).
